# You Property 

**A modern real estate website built with React, Vite, and Tailwind CSS.**

Discover properties, explore residential projects, browse popular locations, and connect with the You Property team to find your ideal home or investment opportunity.

 **Live Website:** [https://you-property.vercel.app/](https://you-property.vercel.app/)

 **GitHub Repository:** [https://github.com/s-pakinamkhaled/You_property](https://github.com/s-pakinamkhaled/You_property)

##  Features

- **Modern UI:** Clean and user-friendly real estate website design.
- **Hero Section:** Introduces the brand and helps visitors start exploring properties.
- **Property Listings:** Browse featured properties and available units.
- **New Projects:** Discover residential developments and investment opportunities.
- **Popular Areas:** Explore properties across different locations.
- **Property Details:** View additional information about selected properties.
- **Interactive Components:** Reusable React components for a consistent user experience.
- **Contact Section:** Provides a way for visitors to get in touch with the team.
- **Responsive Design:** Designed to provide a smooth experience across different screen sizes.

##  Tech Stack

- **React** — Component-based user interface.
- **Vite** — Fast development server and build tool.
- **Tailwind CSS** — Utility-first styling.
- **JavaScript (ES6+)** — Application logic.
- **HTML5 & CSS3** — Website structure and styling.
- **Vercel** — Deployment and hosting.
- **Git & GitHub** — Version control and source code management.

##  Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- [Git](https://git-scm.com/)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/s-pakinamkhaled/You_property.git
```

**2. Navigate to the project directory**

```bash
cd You_property
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the local URL**

Vite will display a local development URL in your terminal, usually:

```text
http://localhost:5173/
```

Open the URL in your browser to explore the website.

##  Build for Production

To create an optimized production build, run:

```bash
npm run build
```

To preview the production build locally, run:

```bash
npm run preview
```

The production files will be generated in the `dist/` directory.
